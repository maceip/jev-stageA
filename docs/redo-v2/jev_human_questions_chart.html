Can Small Security Models Stop Prompt Injection — And Is Fine-Tuning Worth It?

Measured on unseen Banking + Slack agent tools (AgentDojo v1.2.2) across 29,157 offline test decisions and live gpt-5.4-mini runs.
Good outcome: Work Completed / Attacks Caught (Higher = Better)
Failure / Cost: Agent Hijacked / False Alarms (Lower = Better)
Q1: How good is a 4B JEV-style model at stopping prompt injections in a live AI agent?
Answer: Against 1-try attacks it stops 92%–98% of hijacks (34.1% -> 0.8%–2.8%) at about 0.06–0.11s per check — and when fine-tuned to check outgoing tool calls, 75.5% of attacked tasks still finish. Against a 10-try adaptive attacker, JEV alone is bypassed 53% of the time.

Q2: Is it worth fine-tuning an off-the-shelf model — and what makes fine-tuning succeed or fail?
Answer: Yes, when teaching a model a new check — cutting false alarms 6.8x on text (36.9% dev untrained -> 5.4% test balanced) and 3x on tool calls (43.1% -> 14.1% at shared threshold 0.0561). Skewed data or frozen backbones fail.
